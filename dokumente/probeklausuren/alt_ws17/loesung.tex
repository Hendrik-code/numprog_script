	(a)
	Das Verfahren des steilsten Abstiegs (steepest descent) verwendet die Darstellung:
	\begin{align*}
	f(x) = 0.5x^TAx - b^Tx + c
	\end{align*}
	Wir schauen uns den Fixpunkt des Verfahrens $x*$ für die symmetrisch positiv definite Matrix $A$ an.
	\n 
	Erklären Sie anschaulich (keine Formeln!), wie das Verfahren vom Startpunkt zu diesem Fixpunkt läuft. Erklären Sie auch die Richtungen der Bewegungen der einzelnen Iterationen ein.
	\n 
	Welche geometrische Eigenschaft besitzt der Fixpunkt, $f(x)$ betrachtend?
	\sol{\n
		Der Fixpunkt ist eine Nullstelle der Funktion $f$, ein Sattelpunkt (und unter Umständen ein Maximum/Minimum).
		\n 
		Es läuft genau den steilsten Gradienten entlang Richtung Mittelpunkt und damit dem Ziel. Wenn man sich das ganze mit Höhenlinien vorstellt, läuft das Verfahren immer orthogonal zu der Höhenlinie der aktuellen Iteration.
	}

	Jetzt wird eine symmetrisch, negativ definite Matrix $B$ anstelle von $A$ verwendet.
	\n 
	Beschreiben Sie (wieder anschaulich, keine Formeln) wie sich hierdurch das Vorgehen verändert?
	\n 
	Ändert sich hierdurch die Iterationsvorschrift im Gegensatz zum herkömmlichen Verfahren? Begründen Sie mathematisch.
	\n 
	\textbf{Hinweis:} Betrachten Sie die Schrittweite $\alpha$. \\
	Negativ definit bedeutet, dass alle Eigenwert $\lambda_i < 0$ bzw. $x^TBx<0$ für alle Vektoren $x\ne0$.

		Jetzt wird aus steepest descent das steepest ascend Verfahren. Also der steilste Aufstieg wird verwendet als Schrittrichtung, immer noch jeweils orthogonal zu Höhenlinien.

	Eine reelle, tridiagonale Matrix $T \in \mathbb{R}^{n \times n}$ hat die Form
	\begin{align*}
	T = \begin{pmatrix}
	t_{1,1} & t_{1,2} & 0 & \dots & 0 \\
	t_{2,1} & t_{2,2} & t_{2,3} & \ddots & \vdots \\
	0 & t_{3,2} & \ddots & \ddots & 0 \\
	\vdots & \ddots & \ddots & \ddots & t_{n-1,n} \\
	0 & \dots & 0 & t_{n,n-1} & t_{n,n}
	\end{pmatrix}
	\end{align*}
	mit $t_{i,j}  = 0$ wenn $|i-j| > 1$. Wir speichern solche Matrizen als ein 2D-Array inklusive der Einträge mit Nullen.
	\n 
	Folgende Methoden dürfen verwendet werden, als wären sie vollständig und korrekt implementiert worden:		
	\begin{lstlisting}
		// Gibt das Skalarprodukt x^T y zweier Vektoren x,y zurueck
		public static double scalarProd(int n, double[] x, double[] y);
		
		// Gibt die Norm eines Vektors x zurueck:
		public static double compNorm(int n, double[] x);
		
		// Gibt den skalierten Vektor a*x fuer Skalar a und Vektor x zurueck:
		public static double[] scaleVec(int n, double alpha, double[] x);
	\end{lstlisting}
	\lbreak
	(a) 
	Implementieren Sie die folgende Methode möglichst effizient sprich vermeiden Sie unnötige Rechenoperationen.
	\begin{lstlisting}
		// Berechnet das Produkt y = T*x einer tridiagonalen Matrix T mit einem Vektor x und gibt y zurueck:
		public static double[] computeTriDiagMatvec(int n, double[][] T, double[] x) {
		
			double y[] = new double[n];
		
			for (int col = 0; col < n; col++) {
				int startingRow = col - 1;
				if (startingRow < 0) {startingRow = 0;}
				int endingRow = col + 1;
				if (endingRow >= n) {endingRow = n-1;}
				
				for (int row = startingRow; row < col + 1; row++) {
					
					// Nur valide Kombinationen aus reihen- und spaltenindizes
					y[row] += T[row][col] * x[col];
				}
			}
			return y;
		}
	\end{lstlisting}
	\lbreak   
	(b)
	In welcher Laufzeitklasse liegt Ihre Implementierung aus (a)?
	\sol{\n

	(c)

	\begin{align*}
		w^{(k)} &:= T \cdot x^{(k)} \\
		x^{(k+1)} &:= \frac{w^{(k)}}{||w^{(k)}||_2}
	\end{align*}
	\begin{lstlisting}
		public static double[] computeNextEVecApproximation(int n, double[][] T, double[] xk) {
			
			double[] wk = computeTriDiagMatvec(n, T, xk);
			double norm = compNorm(n, wk);
			
			double[] xn = scaleVec(n, (1 / norm), wk);
			return xn;
		}
	\end{lstlisting}
