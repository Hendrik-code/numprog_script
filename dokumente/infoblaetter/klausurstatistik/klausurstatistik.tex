	\textbf{Themen-spezifische Informationen:}\\
	Wichtig ist zu vermerken, dass diese Statistik \textbf{ohne Rücksicht} auf veränderte Themen oder Semesterart (Unterscheidung Sommer- und Wintersemester) gemacht wurde. Es können daher Themen auftreten, die ihr gar nicht hattet. Hier folgt aber erstmal eine kurze Legende:
	\begin{itemize}
		\item Aufgetreten: Anzahl der Klausuren (in Prozent), in welcher der Themenbereiche vorgekommen ist.
		\item Pkte: Anzahl an Punkten pro Klausur, die dieser Themenbereich gegeben hat (avg).
		\item Tasks: Anzahl der Teilaufgaben über diesen Themenbereich pro Klausur (avg).
		\item Pkte/Task: Meint die Anzahl an Punkte, die eine Teilaufgabe dieses Themas gab (avg).
	\end{itemize}
